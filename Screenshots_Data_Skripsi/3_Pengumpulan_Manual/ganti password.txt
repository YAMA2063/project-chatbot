GANTI PASSWORD - STUDENTSITE GUNADARMA

=== CARA GANTI PASSWORD STUDENTSITE ===
1. Login ke Studentsite: https://studentsite.gunadarma.ac.id
2. Klik menu "Ganti Password"
3. Isi form berikut:
   - Password Lama  : masukkan password yang sedang digunakan
   - Password Baru  : masukkan password baru
   - Konfirmasi Password Baru : ulangi password baru
4. Klik tombol "Submit"

=== TIPS KEAMANAN ===
- Gunakan password yang kuat (kombinasi huruf, angka, simbol)
- Jangan bagikan password kepada siapapun
- Ganti password secara berkala
